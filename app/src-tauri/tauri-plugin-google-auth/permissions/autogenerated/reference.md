## Default Permission

Default permissions: allow invoking the Google authorization flow.

#### This default permission set includes the following:

- `allow-start-google-auth`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`google-auth:allow-start-google-auth`

</td>

</td>
</tr>

<tr>

</td>
